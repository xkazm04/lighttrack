# Registry conformance — software-engineering

contributor: mkdol-dev-box · audited: 2026-08-24 · bundle: `software-engineering` (146 subjects)

14 subjects selected against this repo's real surfaces — the three store backends behind one `Store`
trait, the judge/benchmark engine, the ingest clients, the CI ladder, the MCP server, the PII scrub,
and the doc/manifest surfaces. 97 techniques judged. Every technique file was read before the row
was written; the slug name is not the contract.

Statuses: `followed` (the codebase realizes it — cited), `partial` (some of it — what is missing is
cited), `deviation` (it applies and the code contradicts or lacks it), `n/a` (a selected subject's
technique that genuinely does not apply here, with the reason).

A deviation is a finding, not a shame. 14 of the 97 rows are deviations; the ranked backlog at the
bottom is what future waves drain.

## Fixed in this wave

Three deviations named by the harvest wave were verified and closed in the same commit series as
this audit:

- **`test-harness` / `out-of-graph-artifacts`** — `clients/python` and `clients/typescript` shipped
  runnable suites no CI job invoked. Added `clients-python` and `clients-typescript` jobs mirroring
  `clients-rust`, plus a ship-inventory→job table in the workflow header (the technique's written
  interim where the inventory gate does not exist yet).
- **`quality-gates` / `policy-projection`** — `CONTRIBUTING.md` published clippy/fmt as "advisory —
  pre-existing debt" while `ci.yml` had both blocking, and omitted `clients-rust` and `cargo-deny`
  entirely. The table now matches the enforced policy, names `ci.yml` as the authority, and
  `.ai/manifest.yaml`'s `controls` block was corrected in the same change.
- **`quality-gates` / `blocking-by-input-determinism`** — the cargo-deny gate's own TIGHTEN-IT-WHEN
  was actionable, so the invocation was split: `deny-policy` (`check bans licenses sources`,
  deterministic given `Cargo.lock`) now **blocks**; only `deny-advisories` stays advisory, on its
  Monday cron. The decision is recorded at the job with the axis named and the promotion dated.

## Deviations backlog

Ranked by value. The three named deviations this wave fixed are recorded above, not here.

1. **`tracing` / trace-capture — the Python client loses crashed calls entirely.** `Span` emits only
   in `__exit__` (clients/python/lighttrack/client.py:424), so a process killed mid-call produces no
   record. For an observability product this silently drops exactly the calls an operator most needs.
   Write the span at start and settle it on exit.
2. **`job-coordination` / lease-renewal + job-state-machines — a long job can be stolen and then
   have its verdict clobbered.** A fixed 600 s TTL is set once at claim with no renewal
   (crates/runner/src/cli.rs:242), and `finish_job` is unconditioned on current status in all three
   backends, so the reclaimed original can overwrite the verdict the reclaimer wrote. Renew on
   progress and make `finish_job` a conditioned write.
3. **Blocking gates run on an unpinned ruler.** There is no `rust-toolchain.toml`, and CI installs
   whatever `stable` is that day — so `fmt --check` and `clippy -D warnings` are *not* functions of
   the commit, which is the one property that disqualifies a gate from blocking. Observed live this
   wave: fmt was red on six untouched files. Pin the toolchain (the drift itself was reformatted and
   the caveat recorded at ci.yml:278 and CONTRIBUTING.md:171).
4. **`supply-chain` / secret-scanning-architecture — no rung at all.** Public repo, stores other
   people's prompts and completions, and nothing scans a diff or the history for credentials.
   CONTRIBUTING.md tells contributors to check by hand.
5. **`telemetry-pii-redaction` / emit-site-inventory — `metadata` is un-dispositioned.** Arbitrary
   client JSON that already carries `customer_id` (crates/core/src/event.rs:172) is never scrubbed,
   so a customer id shaped like an email flows to storage with the PII scrub on.
6. **`telemetry-pii-redaction` / redact-at-the-cap — unbounded recursion on an attacker-reachable
   path.** `scrub_value` walks arbitrary JSON with no depth, breadth or size cap
   (crates/api/src/redact.rs:253), on the ingest path SECURITY.md names as in scope.
7. **`embedded-db` / quiet-window-maintenance + storage-accounting-and-pruning — unbounded disk.**
   No checkpoint or vacuum scheduling, and no pruning for events, scores or jobs — the three tables
   that actually grow — in a product people self-host and forget.
8. **`quality-gates` / gate-laddering — no local rung exists.** No hooks, no pre-push script; every
   check's first run is a CI round trip. One in-repo script wired into both a pre-push hook and the
   existing jobs would make the remote run a confirmation rather than a discovery.
9. **`docs-sync` — nothing enforces or detects doc drift** (same-change-enforcement,
   doc-rot-detection, source-doc-mapping, catch-up-markers all deviate). Everything currently in
   sync is in sync because a human did it well this wave. The cheapest first step is the one this
   audit's own fix implies: a check that the CONTRIBUTING gate table's rows match ci.yml's job names.
10. **`supply-chain` / update-automation-review — no dependabot or renovate config.** With
    `deny-advisories` red on `h2` and nothing proposing bumps, the advisory lane has a reader but no
    remediation path.
11. **`mcp-tools` / server-composition (partial) — no request timeout and no panic guard.** A hung
    upstream call (crates/mcp/src/client.rs:9) or a handler panic (crates/mcp/src/tools.rs:23) takes
    down the only session the stdio design has.
12. **`cost-metering` / price-tables (partial) — two pricing authorities.** The runner path
    (crates/runner/src/util.rs:117) reimplements pricing without date-suffix or variant resolution
    and defaults an unpriced model to zero cost.
13. **`repo-manifest-standard` / spec-ships-with-artifact — the manifest names a spec no clone can
    resolve** (.ai/manifest.yaml:4).
14. **`embedded-db` / db-self-instrumentation and `test-harness` / long-lane-certification — the
    service has no runtime latency instrumentation for its DB path and no lane on any clock that
    would catch drift over hours.**
15. **`data-access` / row-mapping (partial) — `parse_enum` silently defaults on mismatch**
    (crates/store/src/codec.rs:41), which can misclassify status, provider and operation values
    across every backend without a single error.
